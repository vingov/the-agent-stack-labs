## Selection details that should not be simplified away

Global selection takes the first existing global candidate: config `AGENTS.md`, then the Claude compatibility file when enabled. Project selection tries filename families in order (`AGENTS.md`, then enabled `CLAUDE.md`, then deprecated `CONTEXT.md`). The selected family's upward search can return multiple same-named files between the working directory and worktree boundary. The comment “first project-level match” must not be paraphrased as “exactly one nearest instruction file”: inspect the [actual `findUp` implementation](https://github.com/anomalyco/opencode/blob/3104c1428ec91f809e5ab86631300de41eb6952e/packages/core/src/fs-util.ts#L154-L166). Configured instruction files/globs and URLs are additional paths; URLs were not exercised here.

Ordinary requests assemble system sources and projected messages in [SessionPrompt](https://github.com/anomalyco/opencode/blob/3104c1428ec91f809e5ab86631300de41eb6952e/packages/opencode/src/session/prompt.ts#L1257-L1295), then proceed through model/provider preparation. A compaction request uses its own prompt and no tools; it is not a byte-for-byte replay of the ordinary request.

## Verifier boundaries

`verify_reference.py` recomputes inclusion/exclusion, call identities, output hashes, session continuity, compaction parent/tail relationships, and comparison outcomes. It rejects absent or contradictory required evidence and ignores any added `passed` flag. `test_lab.py` supplies adversarial controls.

`verify_run.py` additionally reads the private raw HTTP bodies, exports, CLI streams and current files after execution. It independently extracts markers and compares bytes/hashes and relevant durable metadata with the receipt: tool status, loaded instructions, compacted marks, message roles, parent links, summary/finish flags, reported usage, and part identity. `test_raw_evidence.py` rejects 10 corruptions in temporary copies of an actual run. These checks cannot prove events beyond the retained artifacts or turn this into a live-model experiment.
